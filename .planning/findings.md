# 发现与技术决策

## 数据存储判断
需求 = 静态教程内容 + 本地练习交互（测验作答、进度标记）。属于"单用户、单浏览器的临时本地状态"，符合规范允许的 localStorage 方案，**不需要数据库**，选择 simple-html 静态模板。

## 内容架构（9 章）
1. 编程世界入门（什么是程序/前后端/全栈路线图）
2. 计算机基础（二进制、内存、进程线程、网络协议 HTTP/TCP）
3. Java SE 核心（环境、语法、面向对象、集合、异常、泛型、IO、多线程、JVM）
4. 前端三件套（HTML/CSS/JS）+ ES6 + Vue/React 概览
5. 数据库（MySQL 安装、SQL、索引、事务、范式、连接池）
6. 后端框架（Maven、Spring、SpringMVC、Boot、MyBatis、RESTful）
7. 中间件（Redis、消息队列、Nginx、ES）
8. 工程化（Git、Linux、Docker、CI/CD、测试）
9. 全栈实战 + 学习路线图（项目、面试、成长路径）

## 交互设计
- 侧边栏章节导航 + 平滑滚动
- 每章含：概念讲解、代码示例、对比表格、思考题
- 测验模块：单选题（点击即判分 + 解析），按章节分组
- 算法模块：力扣风格（题目描述 + 示例 + 思路提示 + 参考答案可展开）
- 阅读进度：章节完成打勾，localStorage 持久化
- 代码高亮：纯 CSS 类手写实现（不引外部库，保证离线可用）

## 约束
- 单 HTML 页面 + 独立 CSS/JS 模块（Vite 打包）
- 中文内容，保姆级 = 每个概念都有"是什么/为什么/怎么做/类比"
- 力扣题附测试用例与复杂度分析
