  - `main.js` bootstrap 改为 `fetchData(name)`：先试 `/api/data/{name}`（后端对缺失记录返回 []，遇空数组继续），再试 `./data/{name}.json`，都失败才算 failed。`src[name]` 记录来源（api/static/null）。
  - 提示条分级：failed>0 显示黄色"两项来源都没有"；staticCount>0 显示蓝色"随包静态数据"提示（6 秒自动消失，属正常状态不是错误）。新增 `.data-warn-static` 样式。
- **部署**：`workbuddy_cloudstudio_deploy` 部署 `D://学系//dist`（port 3000, entry index.html）→ https://45fcddbbf876486b85a672d387698cf5.app.workbuddy.host （verified: true）。
- **验证受限**：沙箱内 curl 无外网（连 baidu 都 HTTP 000），无法 curl 验证；但域名 DNS 解析正常（49.233.240.214），改用 preview_url 在内置浏览器打开。
- **经验**：给依赖后端的前端做静态部署，必须先解决数据源——把 DB 数据导出为随包静态文件 + 前端双源回退，是最省事且两端都能跑的做法。
